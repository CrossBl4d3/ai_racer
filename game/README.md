# AI Racer

A top-down racing game built with Pygame, and a neural network trained
with reinforcement learning to drive it and win.

## Status
- [x] Phase 0: Setup
- [x] Phase 1: Game design
- [x] Phase 2: Playable game
- [ ] Phase 3: AI training environment
- [ ] Phases 4–6: Neural network + training
- [ ] Phases 7–9: Tuning, generalisation, racing opponents

**Human record:** 5.68 s (Track 1, the oval)

## Run it
    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt
    python -m game.race

## Controls
Arrows: drive (hold Down to reverse) · C: checkpoints · H: hitbox · R: restart · Esc: quit
